# Universal Error Code Lookup

## What will it do?

- Querry error code APIs
- Offer option to search google, filtering results e.g. only reddit etc
- Offer option to querry ai(?)

## What new skills I need

- Querrying APIs
- Creating google search redirects
- Create AI querry links if it exists

## Good, better, best outcomes

- **Good:** Webapp that can input an error code, and the app querries an API to display documentation and files
- **Better:** Add local caching for common errors and custom URL builders that open filtered google or StackOverflow / Reddit searches in new tab.
- **Best:** Integrate an LLM (AI) API into the project's backend. This AI can simplify the documentation from the APIs or presents options on how to fix it. Additionally, I could allow user submitted solutions and then the ability to vote on these.
